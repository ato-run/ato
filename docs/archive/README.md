# Archive

Historical evidence, superseded models and past plans remain available for
audit and existing links. They do not define current APIs or establish current
deployment status. Use [Specifications](../specifications/README.md) for authority.

- [2026 records and catalogue](2026/README.md): ops reports, legacy guides,
  consolidation evidence and documentation audit.
- [Legacy accepted RFCs](rfcs-legacy-accepted/README.md): pre-Computation models,
  not current accepted authority.
- [Legacy draft RFCs](rfcs-legacy-draft/README.md).
- [Existing archived RFC tree](../rfcs/archived/): retained instead of creating
  another superseded directory.
- [Ready-State archive](../ready-state/README.md): experiments and host contracts.
- [Internal plans and research](../internal/README.md): historical working material.

English is the current documentation default. Historical Japanese and mixed
sources are preserved as evidence and labelled in the per-file catalogue;
translation must not overwrite the source evidence.
