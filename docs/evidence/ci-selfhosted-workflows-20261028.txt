Reading:
- classic branch protection is unset on main/dev/nightly/stg (404 each);
- the only branch ruleset covering main/dev is protect-main-dev, whose rules are
  deletion, non_fast_forward, update, creation and pull_request; there is no
  required_status_checks rule;
- /rules/branches/main aggregates the rules that apply to the branch and reports
  0 required_status_checks; the only ruleset source is Repository (the token
  lacks admin:org, so org rulesets cannot be listed directly, but this endpoint
  is the aggregate view and shows no Organization-sourced rule);
- therefore the self-hosted migration cannot make merges fail on a stale
  hosted check name, and no required-check list has to be edited.
