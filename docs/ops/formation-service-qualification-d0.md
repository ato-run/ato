## Runtime metric (fixed definition)

Catalog: Node 20.20.2 / 22.14.0, Python 3.11.11 / 3.12.7 / 3.13.1, nothing else.
`runtime_in_current_catalog` = the primary execution runtime kind is in that
catalog **and** the source's declared requirement (if any) is satisfiable by a
catalog version. A readable or exact Go/PHP/Rust/Ruby/JVM/.NET version is never
true. Multi-service apps use their main application process runtime; external
services are a separate field. Undeclared requirements use the Ato default
(Node 20.20.2, Python 3.12.7) and are counted separately.

## First native-process candidates (unchanged, not selected)

Filter: Node or Python family, typed native launch, runtime in catalog, no
mandatory external service.

- **WBO** (Node service, node >=22): package script start: node ./server/server.mjs (plain argv). Remaining: port only via PORT env default (no declared port contract); npm install needs dependency resolution (network); persistent board data dir.
- **JupyterLab** (Python service, python >=3.10): pyproject console script (jupyter-lab). Remaining: source install requires a Yarn 3 workspace frontend build (manager config gap); Python deps unlocked; kernel processes.
- **Kutt** (Node service, node undeclared (Ato default)): package script start: node server/server.js --production (plain argv); separate migrate script. Remaining: two-step typed launch (migrate then start); better-sqlite3 native module needs a compiler in the build sandbox (unverified); npm install needs dependency resolution; PORT via env.
- **Radicale** (Python service, python >=3.9.0): pyproject console script: radicale. Remaining: no dependency lock (unpinned pyproject deps); pip install needs dependency resolution; port only as container EXPOSE / CLI flag.
- **Calibre-Web** (Python service, python >=3.6): pyproject console script: cps. Remaining: requirements are ranges, not a lock; requires a Calibre library state; port not declared.

None is free of the dependency-network gate and none has a native port
contract. Measured blocker order for a native route: (1) a declared launch +
port binding, (2) dependency acquisition policy, (3) execution details. The 17
uncatalogued sources cannot gain verified coverage from native authoring until
a runtime exists.

## Never guessed

No port from a framework, start script or README; no argv from `main.py`,
`cmd/`, a framework name or README shell; Dockerfile CMD/EXPOSE is not treated
as a native launch/port declaration.
