## わかったCLI/運用の改善点

1. Run失敗時にコンテナのstderrが残らない。原因切り分けのため、失敗時にコンテナログを保存する（または`--verbose`で表示する）必要がある。
2. `ato run` 停止後にイメージが残る。Runで取得したイメージを回収するか、残ることを明示する。
3. 停止時に必ず`ato app recover`の判断を求められる。1件ずつ検証する用途では`--on-exit discard`等で完結できるとよい（今回は毎回discardを実行）。
