### Origins, persistence, backup

- Task Board / Calendar organization Resource: hosted authority on
  `staging.api.ato.run` (D1 + instance state). Persistence = the Resource revision
  history and operation receipts; backup is a D1 export/time-travel point plus the
  exported document at a named revision. Restore means importing that point, never
  rewriting history in place.
- Memos: the Memos SQLite database inside the instance state is the source of truth.
  Persistence = the instance state across stop/start (verified in Phase 1). Backup is
  the instance state snapshot taken at a known running point; restore is a stop, state
  restore, start. No DataResource copy exists and none should be created.
- Workspace: references only, so a Workspace backup is redundant with the organization
  D1 backup; losing it rebuilds from the same references.
- All of the above is staging-only until production approval.
