# Ops evidence and compatibility paths

Current runbooks are indexed under [Operations](../operations/README.md).
Historical reports moved to the [2026 archive](../archive/2026/README.md).
Former Markdown paths and heading anchors remain compatibility pages.

Raw JSON, logs, images, compressed artifacts, scripts and the
[dev consolidation evidence](dev-consolidation-20261026/VALIDATION.md) remain
at their original paths. Retaining them here avoids breaking embedded path
references and evidence checksums. These are historical records, not current
deployment status or normative specs. Japanese/mixed-language sources retain
their original text; the [inventory](../archive/2026/documentation-reorganization/inventory.tsv)
labels language and classification per file.

See the [retention assessment](../archive/2026/documentation-reorganization/EVIDENCE-RETENTION.md)
before proposing external storage or deleting a large evidence file.
