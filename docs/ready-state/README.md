# Ready-State implementation archive

> **Status: historical and implementation-specific.** Files in this directory
> document experiments, benchmarks, host contracts, and delivery plans for the
> former Ready-State snapshot path. They may still be useful as engineering
> evidence, but they do not define current Capsule identity or the Semantic
> Core.

In the current model, readiness is expressed by a Contract and snapshots are
possible Materializations. A Capsule is the logical Computation point, not the
Ready-State artifact, VM, process checkpoint, or restore backend.

Start with [Materialization](../concepts/materialization.md) and the accepted
[Materialization RFC](../rfcs/accepted/MATERIALIZATION.md).
