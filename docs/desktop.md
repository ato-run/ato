# Desktop

Status: Current technical reference.

The Desktop is developed and released from the separate
[`ato-run/ato-desktop`](https://github.com/ato-run/ato-desktop) repository. The
current product entry is the Web service ato.run. Desktop does not define a
different Capsule identity; its IPC boundary is owned by `ato-ipc` in this
repository.

The earlier in-tree `apps/desktop` launcher and `apps/desktop-tauri` shell were
removed for the 0.1.0 tree; they remain in history and in
<https://github.com/ato-run/ato-archive-2026-11>.
