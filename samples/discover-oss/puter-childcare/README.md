# Puter Childcare staging observation

On 2026-11-06, the [Puter Childcare Early Alpha listing](https://stg-app.ato.run/?c=dapp_01M6N1Y9S8Q0SV45HEX8DCXDQ1)
admitted a public trial. Opening it from the window's `…` menu in a separate
Chrome tab reached the early-alpha screen. Its built-in demo displayed a
sample school, and checking in a sample child changed that child's status and
the demo's present count. The app states that demo changes stay in that tab
and disappear when it is left.

The embedded frame was still loading when the new-tab action was selected; a
completed embedded launch, a signed-in Puter account, family sharing,
persistent real data, and billing are not verified. This early-alpha demo must
not be used for actual children's records or billing. The source link points
to Puter's Everything repository; the exact source revision and complete
distribution provenance for this particular staging listing remain unverified.
