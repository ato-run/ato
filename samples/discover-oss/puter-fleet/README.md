# Puter Fleet staging observation

On 2026-11-06, the [Puter Fleet Early Alpha listing](https://stg-app.ato.run/?c=dapp_01M6N5DSC4D8SMCT4FA5C7XNTZ)
opened its public trial from the window's `…` menu in a separate Chrome tab.
The app's sample fleet loaded, and a synthetic issue was added to a sample
vehicle and appeared in its issue details. The demo states that changes stay
in the tab and disappear when it is left.

The embedded frame was still loading when the new-tab action was selected;
a completed embedded launch, signed-in persistence, sharing, and integration
with actual fleet records are unverified. The app itself warns against relying
on this early-alpha version for real fleet records. This Puter demo is a
different project from Fleetbase; it does not satisfy Fleetbase's staging
acceptance. The particular listing's source revision and complete distribution
provenance remain unverified.
