# Puter Property Management staging observation

On 2026-11-06, the [Puter Property Management Early Alpha listing](https://stg-app.ato.run/?c=dapp_01M6N57JPTET834RHDSC5V1C63)
opened its public trial from the window's `…` menu in a separate Chrome tab.
In the built-in sample portfolio, accepting a sample maintenance request
reduced the displayed new-request count from three to two. The demo states
that changes stay in that tab and disappear when it is left.

The embedded frame was still loading when the new-tab action was selected;
a completed embedded launch, signed-in persistence, sharing and accounting
remain unverified. The app warns against using this early-alpha version for
real tenant, lease or accounting records. The exact source revision and
complete distribution provenance for this staging listing remain unverified.
